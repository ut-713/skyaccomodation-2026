# Sky Accommodation

Marketing website for Sky Accommodation, Wollongong — nightly & weekly rooms,
permanent student accommodation, and corporate stays. Built with Next.js
(App Router), TypeScript and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Pages

- `/` — Home
- `/rates` — Nightly & weekly rates
- `/student-accommodation` — Permanent student rooms
- `/corporate-stays` — Mid-week corporate packages
- `/attractions` — Local Wollongong attractions
- `/gallery` — Photo gallery (placeholder images)
- `/location` — Map & directions
- `/contact` — Enquiry form
